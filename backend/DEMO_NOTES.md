# Demo notes

1. Start the backend with `python backend/app.py`.
2. Start the frontend with `pnpm dev`.
3. Select **Try sample policy**, then analyze it.
4. Point out the Trust Score, risk signal, category explanations, source excerpts, rule findings, and limitations.
5. Upload a `.txt` policy to demonstrate equivalent submission behavior.
6. Demonstrate short-text validation and explain that the analysis is educational, not legal advice.

Before presenting, run the backend suite and frontend build, confirm the current rules are frozen, and record any rule changes in `SCORING_RUBRIC.md`.
